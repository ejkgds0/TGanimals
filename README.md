TGanimals — это Telegram-бот, который определяет вид животного по фотографии.
Он включает в себя 5 обученных моделей:
  Основная модель: 64 класса животных (точность ~92%)
  Кошки: 17 пород
  Собаки: 30 пород
  Обезьяны: 22 вида
  Птицы: 20 видов

Бот доступен по нику @ID_AnimalBot, но активен только при локальном запуске.
